# 个人教材续读位置

1. 已保存的个人教材提供“保存为续读位置”“回到续读位置”“重新读取位置”。学生主动选择续读点，临时滚动或回看不覆盖它。原有浏览器滚动恢复仍保留；服务器续读点通过按钮恢复，不在异步正文加载时突然跳页。
2. 位置使用材料编号、材料内容指纹、段落锚点和段内像素偏移。排版与屏幕尺寸变化时段内位置可能略有偏移；材料内容变化后不直接套用旧位置。不是所有文档形式通用的位置协议。
3. 每个课程的 reading.sqlite3 保存本人每份材料的最新位置。读取和写入均验证材料归属；受保护部署还验证登录身份。阅读位置独立版本控制，不递增学习诊断版本，不添加学习证据、不调用模型、不判定掌握。
4. 两个页面同时保存时，较旧版本拒绝覆盖；界面说明冲突，学生重新读取后再决定是否保存。相同最后请求与内容可重试，不重复递增版本；旧请求在其他成功保存之后不保证仍可重放。
5. 接口为 GET/POST `/api/learning/reading-position`。查询携带 course_id、student_id、material_id；写入正文另含 request_id、expected_revision、anchor、offset。只接受材料现有段落或 top，拒绝无效和非有限偏移。
6. 已验证新浏览器环境在没有本地滚动缓存时读取服务器位置并恢复；这项工程验证使用同一合成编号。真实身份恢复另由访问模块验证，不将开发编号当作跨设备登录凭证。
7. 首页通过 `GET /api/learning/continue?student_id=...` 查询当前身份跨课程的最近 5 个有效续读点，合并个人教材、PDF 和视频，按服务端保存时间排序；不复制材料或创建额外学习进度。无服务器记录时才使用本浏览器最近课程，明确区别两者；读取失败提供重试而不伪装为空记录。每课程每类候选读取最近 10 项，不是无界检索。
8. 旧 reading.sqlite3 增加 updated_at 列，保留已有位置；旧记录时间未知，显示为历史位置，不编造最近时间。材料删除或内容指纹变化后不再出现在有效续读列表。
9. 已在无本地课程／滚动缓存的新浏览器环境验证首页发现教材续读点；后续也验证首页进入 PDF／视频材料后恢复保存位置。实验活动的统一入口和完整账户删除时的阅读位置清理仍待完成，不能宣称所有活动都已自动跨设备续学。

## 课程 PDF 与 PDF 版课件阅读

1. 在“选择学习材料”中，当前可用课程资源的本地文件链接可打开工作台 PDF 阅读器，无须先生成讲解或引用。资源链接严格限定 `/api/documents/<32位文件编号>/source`，可附 `#page=正整数`；不是任意本地路径、任意网址代理或未入课程资料库浏览入口。课程资源须明确关联并处于可用状态，原有引用页预览继续独立按引用范围核验。
2. 阅读器支持完整文件页码、前后翻页、文字／原版式切换、100／150／200% 显示及位置保存。原版式服务端渲染单页图片，最长边不超过 2200 像素，不执行 PDF 中脚本；文字直接提取当前原页，没有自动 OCR。原生 PPTX 未支持，应先提供合法可用的 PDF 版课件；非 PDF 给出明确提示，不用生成文本冒充原版式。
3. 文件内容摘要、当前课程版本和资源定义共同限定阅读版本；页请求与保存请求均携带该版本签名。文件或资源变化后旧请求拒绝，重新读取后旧位置失效，不将旧书签套在新文件。当前逐次检查文件摘要，尚未完成大文件与高并发性能验证。
4. 同一 reading.sqlite3 中的 `document_resource_positions` 按课程存储位置、按学习者和资源隔离。保存页码、模式、缩放和独立修订号；重复最后请求幂等、跨页并发拒绝旧版本覆盖。刷新后再次打开该资源恢复已保存位置，阅读不增加知识证据或改变掌握状态。
5. 接口为 GET `/api/tutor/resource-document`、GET `/api/tutor/resource-document-page`、POST `/api/tutor/resource-document-position`。受保护部署必须匹配登录身份；返回均禁止缓存，图片附 nosniff。未开启身份保护的开发模式不适合真实学生数据。
6. PDF 与视频有效书签已纳入首页“继续学习”。入口定位对应课程、知识点和材料选择器；PDF 打开时恢复已保存页码，视频仍由学生主动加载并恢复时间，不自动连接外部视频或播放。失效或已撤下资源不进入有效列表，旧版书签时间未知时显示历史位置，不编造最近时间。
7. 未完成的当前 ML Lab 轮次也纳入同一个首页入口，按已有轮次创建／操作事件时间排序，不通过访问首页刷新活动时间。点击返回课程内现有实验页，不自动新建轮次；课程、映射或契约变化明确提示保留旧记录后开始新版。已完成轮次不当成待完成续学，课程不再具备合法实验映射时不展示不可用入口；历史实验仍保留在原记录中。本入口不涵盖所有独立测验或任意未来活动。

## 教学推荐与自主选择

视频资源可选 `video_segment: {start_seconds: 12.5, end_seconds: 50}`，只允许有限数值且 `0 <= start < end <= 604800`。它随课程版本与资源签名保存，进入现有核验与教学上下文，表示课程标注的推荐范围，不代表模型已经看过视频。学生主动打开播放器后可定位推荐起点，定位保持暂停，不强制在终点截断；仍可看完整视频并保存任意有效位置。若推荐终点超过浏览器实际读取的时长，提示核对资源，不静默截短或伪称定位成功。尚未实现字幕索引、自动片段理解或外部文件变更检测。

1. 智能体获得有限范围内的可用资源清单，可在讲解或活动安排中选择最多三项并说明用途；没有合适材料时留空。服务端拒绝重复、清单之外以及不关联目标知识点的推荐，不接受模型提供的新资源地址。
2. 对话和保存的个人教材显示同一份历史推荐。点击后仍使用课程材料选择器，先核对当前资源，再由学生选择打开原文件、PDF 阅读器或视频播放器。资源失效时显示提示，不悄悄改写历史理由。
3. 推荐理由与资源快照随教材保存，导出保留标题、适用范围和说明，以及存在时的当时视频起止秒数；旧记录没有片段时不从新课程补造。对话和教材标注历史片段，打开资源仍核对当前版本。推荐或打开本身不代表学生已阅读、完成活动或掌握。学生仍可从工作台选择其他可用形式，不设置逐次人工审核。

## 导入资料与资源关联

1. 将资料中的选定概念导入课程时，同步生成一份原文件资源草稿，关联已导入的概念及其原文依据；作者未提供时明确标为待补，不编造作者。上传文件本身不会自动发布，只有纳入课程并通过现有自动核验后，资源才进入学生清单和智能体上下文。
2. 同一资料重复或分批导入复用同一资源，不复制节点或资源；旧课程没有对应资源时可通过再次导入补齐。保留已有自定义标题等元数据；遇到同编号的非自动导入资源，拒绝覆盖并要求解决冲突。
3. 资源节点关联上限与课程的 500 节点上限一致，避免新增资源步骤将原有文档导入能力降为 200 节点；整体课程规模和核验上下文限制仍然有效，过大的自动核验范围仍需拆分。

## 个人成果 PDF 导出容量

1. 个人材料、阶段报告和教材汇编共用每个服务进程最多两个 PDF 排版名额，超出立即返回 429，提示稍后手动重试，不创建无界等待队列。此数值是保守工程限制，不是负载测试得出的最优并发量。
2. 成功、排版异常或服务端任务取消都会释放名额。浏览器“取消下载等待”只停止等待，不保证服务端排版立即终止；正在运行的任务仍占名额直到结束或被服务端取消。
3. 不修改原材料、报告或学习状态，也不自动重试渲染。此限制仅覆盖个人成果 PDF，不覆盖旧讲义导出、Word、模型、视频解码或整个服务；多进程部署的总量会随进程数增加，仍需网关和实际容量验证。
