# 匿名身份与受保护运行说明

本说明针对 `feat/agent-learning-platform` 当前实现。它不是公网部署已经通过验收的证明。

## 1 两种模式

1. 默认保留本地开发模式，旧入口与合成测试继续可用。浏览器中的匿名编号仅用于选取记录，不是身份验证；此模式不可公开给真实学生使用。
2. 设置服务端环境变量 `PLIAC_REQUIRE_AUTH=1` 后启用受保护模式。学生先建立匿名身份或提供恢复码；API 由服务端会话校验，不依赖地址中的编号授予权限。
3. 当前会话期限为 24 小时，刷新页面不会延长期限。到期用恢复码重新进入；每次恢复会换发新码，旧码及该身份的旧会话全部失效。恢复码不是供管理员查询学生记录的公开编号。
4. 管理身份需要环境变量 `PLIAC_ADMIN_SECRET`，使用随机生成且至少 32 字符的凭证。不要使用示例口令或课程名称，不在仓库、前端、截图、终端记录和普通日志中展示真实凭证。未配置时管理登录失败，不自动创建默认管理员。
5. 本次开发没有改动真实运行环境配置。准备共享部署时必须显式核对模式，不能认为代码中存在权限模块就默认保护已开启。

## 2 数据和权限

1. 身份及会话摘要存于当前默认课程输出目录的 `identities.sqlite3`，不包含恢复码或会话令牌明文；与课程学习记录一起按权限管理和备份。
2. 已有开发编号不会自动认领或合并。即使有人知道旧编号，也不能据此取得身份。实际迁移需要另行核对归属与备份，不修改或删除旧学习记录。
3. 学生可以使用公开可用课程、自己的教学与实验记录、笔记、报告和导出。学生不可直接提交诊断结论、修改公共知识、访问课程草稿或完整后台资料库。
4. 教学来源文件仅在关联到可用课程节点时对已登录学生开放。当前课程默认面向全部已登录学习者，不包含“每门课单独选课授权”；若以后接入受限版权课程，需要另设课程访问范围。不要把只允许展示几个片段的完整文件直接放入可共享来源。
5. 旧 HTML 页面仍可打开，但受保护 API 不因此绕过权限。未适配的旧学生讲义工具不因学生看得见页面就具有后台操作权；后续须补学生只读入口，不以放开资料库或管理路由解决。
6. 显式退出清除本浏览器 `pliac.*` 的私有草稿、位置和任务恢复缓存，保留主题；已提交的服务端数据不删除。界面在退出前说明此行为。当前不把退出、清空笔记最新内容或恢复身份称为完成隐私删除。

## 3 连接与限次边界

1. 受保护共享访问必须使用 HTTPS；本机实际回环连接可使用 HTTP。只配置域名或在请求头写 `X-Forwarded-For` 不能代替正确部署。
2. 反向代理部署必须配置可信代理来源，并阻止绕过代理直接访问后端端口。代理应覆盖而非透传任意客户端的转发头；需实际验证 FastAPI 接收到的协议、Host 与来源地址。
3. 非安全读取以外的请求拒绝不同 Origin 及跨站 Fetch Metadata；会话 Cookie 使用 HttpOnly、SameSite=strict，共享 HTTPS 下使用 Secure。跨域前端不在当前支持范围，应使用同源反向代理。
4. 每个来源地址、每种身份操作在十分钟内最多允许 20 次新建匿名档案，或 10 次恢复/管理登录尝试。超过返回 429；共享校园出口可能共用地址，真实并发试用前需评估策略与网关限制。数据库限次跨进程共享，不把内存计数当作部署保证。
5. 身份限次不覆盖模型调用费用、整个服务的拒绝服务防护或管理员操作审计。个人成果 PDF 另有每个服务进程两个排版名额，超出返回 429（见 reading-runtime.md），并非跨进程总容量或全部导出防护。后续共享部署还需配置资源与费用上限。

## 4 本批验证与后续关口

1. `tests/test_access.py` 在隔离临时存储中检查会话、恢复、越权、管理和来源边界；不使用真实学生记录。
2. `tests/test_ui_access.py` 在临时本机服务与真实 Chromium 中验证前端身份流程，报告在 `outputs/verification/identity-ui-report.json`。截图遮蔽合成恢复码；测试不会把身份数据库带入生产输出目录。
3. 正式部署前还要验证所有新增媒体和导出入口、配置错误时的行为、备份恢复、隐私删除、实际网络与反向代理、费用限制及真实课程质量。无需逐次人工审批教学，但上述工程和数据边界不能省略。

## 5 删除准备的数据清单

1. `scripts/inspect_learner_data.py <课程运行根目录> <明确的学习编号>` 是本地维护者只读工具。使用项目 Python，从默认 `course_graph` 运行根目录扫描包含子课程与演示课程的记录，统计该编号的历史文件、版本、已识别数据库行数及摄像头片段字节数，不输出正文、视频、恢复码或模型密钥。
2. 不调用原存储类的连接初始化或媒体过期清理；数据库以只读模式查询，不创建缺失数据库。目录重定向拒绝，未知数据表另列，不能把未识别的数据当作不存在。共享来源地址限次记录不强行归属于某个学生。
3. 这不是全局原子快照，也不涵盖浏览器、下载文件、外部备份、模型提供方日志或未识别文件。维护报告本身也应保管在受控位置。只能作为删除范围核对的一部分，不是删除授权、删除执行结果或彻底擦除证明。
4. 清单不执行删除。离线清理工具见下节，在线自助删除、在途任务隔离及外部副本处理仍未完成。

## 6 离线清理已识别记录

1. `scripts/delete_learner_data.py <课程运行根目录> <学习编号>` 默认只输出清单。只有同时添加 `--execute --confirm-offline --confirm-student <同一学习编号>` 才执行。实际执行前须由有权限的维护者核实本人请求与范围，正常停止全部读写服务及模型／媒体任务，并明确原备份处置；这不是可直接复制到真实数据上的示范删除命令。
2. 离线确认是操作者声明，程序不能证明服务已停止。程序进一步拒绝写锁、目标学习者 running 任务、未知数据表、非预期数据库、重定向目录、管理员身份以及该编号作为操作人涉及其他学习者的审计记录，避免自动决定此类保留政策。
3. 清理已识别数据库中的该学习者记录，先删除媒体片段再删除会话，撤除身份及登录会话；递归删除仅限校验后的该编号哈希历史目录，含全部历史版本。其他学习者、课程及公共资料不作为删除目标。执行后重新核对已识别记录为空。
4. 各数据库与文件系统之间不是原子事务。发生中途失败会明确报告可能部分完成，必须保持服务停止，核对清单后继续；不要将失败当成未发生任何删除。已删除记录不能由工具撤销，也不自动生成一份新的敏感数据备份。
5. 此工具不承诺物理介质擦除、SQLite 日志残留清除、外部备份／下载／浏览器／模型提供方记录删除。不得恢复含已撤回数据的旧备份后直接开放服务；开发模式同编号重新写入也未被持久禁用。因此这是离线已识别记录清理，不是完整隐私删除验收或在线删除功能。
