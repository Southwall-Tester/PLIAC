## 第八十四批手机导航焦点与退出修复

## 第二十一批匿名身份与访问隔离

1. 增加显式受保护模式 `PLIAC_REQUIRE_AUTH=1`。服务端随机分配匿名身份与 HttpOnly 会话，不能由学生填写编号认领已有记录；恢复码仅显示一次，服务端只存摘要。恢复时轮换恢复码并撤销该身份全部旧会话，正常退出撤销当前会话。
2. 学生 API 采用明确允许清单，核对查询和请求正文的学习编号。旧学习读取、图谱导出、Lab、任务状态及个人 PDF 同样受检查；直接写诊断、知识生效、草稿、资料库和教师接口需要管理身份。公开课程目录只返回可用版本，学生只能读取已关联可用课程节点的来源文件，不直接开放资料库。
3. 管理凭证由服务端环境配置，至少 32 字符。写入检查跨站来源；共享连接要求 HTTPS，只有实际回环地址允许本机 HTTP。匿名建档、恢复及管理登录按来源地址和操作在十分钟窗口内限次；反向代理真实来源配置必须在共享部署时核对，不从任意客户端头信任来源地址。
4. 新前端先核验身份再挂载学习界面，提供建档、恢复码确认和账户退出。没有新建“首次学习准备”一级入口；身份入口与课程内起点准备分开。恢复码不写入浏览器持久存储。已保存学习记录留在服务端，显式退出清除浏览器私有草稿和任务缓存，界面预先说明；不将此行为称为隐私删除。
5. 课程位置、未发送问题和作答草稿补充身份命名空间；当前标签页固定自身身份，其他标签页切换或退出时重新核验。浏览器测试覆盖两个独立身份、跨浏览器恢复、旧会话失效、新身份不继承旧草稿、同浏览器其他标签页退出，以及窄屏恢复码页面。已查看桌面入口和手机截图，恢复码在截图中遮蔽。
6. 新增 8 项服务端测试，包含旧接口越权、正文在权限检查后正常传递、管理权限、跨站拒绝、会话到期、恢复码轮换、限次、课程草稿与来源边界。全量 unittest 248 项通过（55.105 秒），前端生产构建通过；身份、原导航、教学恢复和核验—Lab—报告 PDF 浏览器回归通过。使用隔离临时库及合成身份，未迁移真实记录、未付费调用模型、未启用用户运行服务的共享模式。
7. 当前仍不能宣布正式共享部署安全完成：开发模式默认保留；旧开发编号不自动迁移；媒体授权、隐私删除、部署与备份恢复、模型调用配额和全面旧讲义学生入口适配仍需完成。身份操作限次不是模型费用或服务器整体容量控制。完整运行边界见 `access-runtime.md`。

## 第二十二批事件驱动的教学接续

1. 增加服务端 `teaching_flow` 状态，保存当前活动和待处理触发的编号、课程版本、节点、原因及源事件。React 起点表单默认启用智能体接续；学生可选择起始知识点或先自主浏览，不影响原有目标、自评及记录。旧开发入口不被静默改为自动付费调用。
2. 目标保存后触发起点安排；主控核验活动先保存原始作答，再自动接评价。评价完成触发后续教学，Lab 合同完成记录实验后核验触发；读完小节只生成继续学习事件，不产生掌握证据。没有预设判据时仍不凭模型宣告掌握。
3. 自动安排复用持久化生成任务，按服务端触发与学习版本统一请求编号，不同标签页不能仅靠换请求编号重复生成同一触发。刷新可恢复运行中或已生成请求；失败不无限自动重试，保留已存材料并提供明确重试入口。
4. 支持暂停、恢复和围绕当前知识点重新安排。暂停或目标改变后，旧生成不能越过版本核验提交；旧目标任务的后来评价不覆盖新目标。暂停期间完成的当前核验会保留下一步触发，恢复后再处理；课程版本变化不能继续冒用旧活动。
5. 新活动保存后先显示入口，不强制跳走或替换正在查看的结果。历史材料固定关联自己的核验题，不因创建下一题就显示另一份作答。手机检查发现核验区贴近屏幕边缘，已补内边距并重新截图核验。
6. 新增 6 项服务端教学流程测试；既有真实 Lab 完整实验测试增加完成后触发、仍无概念诊断的断言。浏览器模拟模型走通目标—初诊—作答与评价—补学—阅读完成—未曝光复测，覆盖生成中刷新、错误停止、显式重试及暂停后刷新。全量 unittest 254 项通过（51.467 秒）；前端构建、原教学对话、身份隔离、核验—实验—报告导出浏览器回归通过。本批未调用付费模型或使用真实学生。
7. 尚非完整教学主控验收：目前从学生选定节点及其邻域编排，课程级目标协商、范围计划、自动阶段收束、学习偏好修正和正式课程语义质量仍须实现或验证。事件在工作台打开时处理，不是无人在线也持续消耗模型额度的后台循环。媒体、Word 和真实试用等原指南范围不因本批完成而缩减。

## 第二十三批课程目标与学习范围规划

1. 起点表单区分系统学习、补知识点、完成任务，以及混合、讲解、练习和 Lab 偏好。智能体基于当前课程节点、真实先修、已保存目标和状态提出范围、顺序与起点；课程外目标和不可用实验应先澄清，不制造资源。系统学习不能静默缩成少数节点。
2. 学生采用或调整自己的范围后触发教学主控，这不是教师审批。计划保存课程版本、目标和建议顺序；补前置与目标范围分开。选择起点、采用计划、阅读或实验完成本身均不产生掌握证据。
3. 规划复用持久生成任务，生成中刷新恢复同一请求；旧目标不能覆盖新目标。暂停后拒绝新模型调用；同一已存请求不得改称另一课程版本。前端课程版本变化时提示重新规划并隐藏旧计划采用按钮，历史计划仍可查看。
4. 已采用计划参与教学上下文；评价后当前节点有掌握证据时可按保存顺序寻找尚未掌握的目标，阅读完成或证据不足不会据此自动推进知识状态。此部分有服务端单元覆盖，跨多个远距离节点的真实模型教学质量仍待验证。
5. 实际浏览器使用模拟模型验证目标保存、规划中刷新、单次生成、采用后自动教学、作答评价、补学、失败显式重试、未曝光复测及暂停后刷新。没有自动跳走正在阅读的历史材料。检查手机截图，页面无整体横向溢出；模型调用为合成测试，不是实际学生试用。
6. 前端生产构建通过；初次全量 unittest 261 项通过（56.893 秒），随后新增两项服务端保护后规划测试组 9 项通过（2.041 秒）。身份隔离浏览器回归通过。测试数量分属先后两次执行，不将分组复测写成新增后的全量复测。
7. 尚需自动阶段收束、正式课程与判据、真实模型语义评测；摄像头、Word 导出、统一媒体与 Lab 体验及真实试用等既定范围继续保留。本批没有付费调用模型、提交或推送代码。

## 第二十四批学习范围的自动阶段收束

1. 在评价提交并重新计算知识状态后，检查当前课程版本中已采用计划的全部目标。只有每个目标均有掌握证据支持才收束；部分完成、受助或题目曝光后的成功不触发。采用计划时若已有足够证据也可形成当时快照，不重复制造诊断。
2. 阶段报告复用已有快照结构，限定本次目标节点及其证据、笔记和教材，关联计划编号与保存版本。不包含其他范围笔记或私有任务答案。报告说明其结论是当时、该范围内的证据支持，不代表整门课程或永久掌握。
3. 收束与评价在同一学习记录事务中保存，清除待处理教学触发并停止自动安排。重复提交不会新增报告；工作台提供阶段总结入口，档案沿用原报告索引，原始回答和历史诊断不删除。
4. 新增 3 项集成测试，以实际保存的合成作答和诊断核验完整、部分、曝光三种路径，验证范围隔离、重复请求、报告版本与后续笔记不改变旧快照。全量 unittest 266 项通过（58.369 秒），生产构建通过。
5. 浏览器走通初测错误—补学—未曝光复测通过—自动保存一份阶段报告—打开与刷新—不再自动调用模型。首轮测试误用了初测答案定位复测选项，修正为读取隔离测试库中实际复测题的选项后通过，未改变题目或放宽掌握标准。测试使用模拟模型与合成学生，不证明真实教学效果。
6. 容量限制沿用报告上限 100 份：达到上限时暂不自动生成，且不回滚学生答案或诊断；容量治理与显式提示仍待完善。延后复习、跨版本结论适用性、完整个人教材汇编、Word、多模态和真实试用继续列入剩余范围，未因此缩减目标。
