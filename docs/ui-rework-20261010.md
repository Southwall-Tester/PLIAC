## 0 背景与决策

1. 用户反馈：首页无可操作中心、文案冗余（自我辩护式说明）、字体粗糊、工作台中栏把讲解/检验/笔记/总结纵向堆叠，整体“AI 味”重。
2. 根因：前端没有“当前学习活动”的概念，`main.tsx` 用网址参数优先级猜测显示内容，所有功能面板同时铺开。
3. 决策（用户已授权 Claude 直接改，2026-10-10）：
   1. 技术栈不变：React + TypeScript + Vite + 现有 FastAPI。后端本轮不改。
   2. 建立设计规范（字体、字号、颜色、间距），三主题共用。
   3. 工作台引入“活动”层：中栏一次只渲染一个活动；左栏路径，右栏教学对话；笔记、记忆、总结等收进抽屉，不删除功能。
   4. 首页以“智能体给出的下一步安排”为中心，新用户显示目标输入；删除口号与开发说明。
   5. 演示课 `ml_acceptance_demo` 在首页标为“体验课”；未就绪课程不作为死入口展示。
   6. 社区、公开课程、视频/PPT 生成不在本轮范围。视频先用 B 站等外部优质课程按集/时间点内嵌（后续）。
4. 不提交、不推送；改动保留在工作区供用户验收。
