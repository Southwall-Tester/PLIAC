# 账号与个性化学习流程（0.12）

默认入口 `/` 先验证登录状态，未登录转到 `/login`。本地注册/登录使用账号和密码；账号表独立保存在 `outputs/account`，密码保存 PBKDF2-SHA256 派生结果与随机盐，会话仅保存随机 Cookie 的哈希。每个账号有固定的 `student_id` 和 `assistant_owner`；服务器从登录会话绑定身份并拒绝跨账号请求。当前提供本地账号，邮件找回密码、外部身份提供商和教师角色授权属于后续账号能力。

模型服务与账号密码分开：当前平台由维护者通过服务端环境变量或可选的 `config/models.json` 配置统一服务，学生登录时无需填写 API Key。没有该文件时按 `LEARNMARGIN_*` 配置读取模型；默认 DeepSeek 服务可读取 `DEEPSEEK_API_KEY`。用户自带 Key 的模型设置界面尚未实现，切勿将服务端凭证写入浏览器或学习画像。

## 学生主线

1. 登录后选择课程，进入“我的路线”。
2. 填写学习目标、已有基础、兴趣；知识点默认“还没学过”，章节默认收起，用户只需勾选学过的内容。勾选后可选择“我已经会了”或“学过，还不确定”。
3. 起始核验只从用户勾选的内容中选取最多三道题，综合自评、学习目标和覆盖情况选择。全部未学过时直接安排路线，保存空的基测证据，不生成核验结论。
4. 作答原文存为独立 baseline evidence。真实模型根据题面、教师参考、原话和自评判断本次表现；诊断必须关联有效知识点和连续原话。程序再将自评与表现合成课程初始画像，例如自评偏高、核验支持已有基础、表现优于自评、需补充证据。
5. 模型给出学习优先级、原因、重点、节奏。系统按课程的 prerequisite 边进行拓扑排序，补齐必要先修；相关、易混淆和共现关系不变成学习顺序约束。没有模型配置时用明确标识的课程算法安排基础路线，核验信号保留待进一步检查。等待期间展示真实处理阶段与已等待时间，模型阶段使用活动进度条。
6. 点击“开始学习”进入当前片段。课程已有正文与练习立即可用，个性化讲义、图谱和习题在后台准备。页面没有首次“生成”配置。
7. “课程全貌”保留线性目录、知识图谱、学过/未学状态和知识关系；用户可查看整体体系，再回到当前学习。

自由提问统一使用右侧学习助手。当前学习直接显示 LearnMargin 生成的个性化讲义；准备期间可先阅读课程已有内容，完成后自动切换。正文旁的小节练习用于独立作答与学习证据，输入后自动保存草稿。旧版已记录的提问保留为只读折叠历史。学生页面不渲染诊断手册、原始作答证据列表或管理用章节报告；这些数据保留在后台与教师复核页面。课程全貌按实际学习记录显示未学习、正在学习、已学习和练习已通过。

## 个性化内容与重生成

学生 `/course-reader` 接收当前片段范围，自动复用或准备内容。服务器画像包括学习目标、背景、兴趣、起点评测的校准结果、当前路线的教学重点与节奏，以及可用的账号助手画像。同一学生、范围和画像指纹复用已有任务；其他账号的个人产物分别保存。

“重新生成”用于修改当前版本，可填写新的学习需要，并选择初次学习或期末复习。每次重生成读取最新画像，产生新版本，已有版本和原始作答继续保留。失败任务显示实际状态，自动进入页面不会无限重试。管理人员可使用 `mode=author` 查看原有生成工具；这只是管理界面模式，未宣称独立角色权限。

## 存储与判定边界

- 课程原始自评、基础评测原话、模型诊断、初始画像和路线分别保存。起点评测记录在 `learner.workspace.journey`，包含 `active` 和历史版本。
- 原有正式课程掌握度仍走学习证据与审核契约；基测和聊天模型推断用于教学安排。学习路线和课堂真实效果需分别验证。
- 助手在当前课程读取本账号的初始画像和当前教学重点；对话形成的最新偏好可进入后续讲解和重新生成。
- 原始服务 `learning_agent.main:app`、课程版本与不可变验收课程数据继续保留。

## 验证入口

```powershell
python -X utf8 -m unittest discover -s tests -p "test_accounts.py"
python -X utf8 -m unittest discover -s tests -p "test_journey.py"
python -X utf8 tests/test_ui_journey.py
python -X utf8 scripts/verify_personalized_journey.py
```

浏览器回归使用临时账户、临时课程记录和合成模型。真实模型验证也使用明确标记的合成学习者，结果写入 `outputs/verification/journey/live-model.json`，不会写入真实账号或产生正式掌握结论。
