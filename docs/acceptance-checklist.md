# 平台首轮验收清单

本清单对应 `build-guide-20261009.md` 第 12 节的原始范围，补充 `implementation-status.md` 的逐批记录。工程测试使用临时课程、合成学习者和模拟模型；不能据此宣称正式教学、真实摄像头试用或模型质量已经验收。当前结论仍是平台未完成首轮整体验收。

## 1 十六项场景与证据边界

| 编号 | 当前可以核对的工程证据 | 仍需完成的证明 |
| --- | --- | --- |
| A01 自评会但解释不清 | `test_teaching_flow.py` 检查起点不产生掌握；`test_ui_teaching_flow.py` 走通初诊、作答、补学和独立复测 | 正式课程中由真实模型处理自信但错误的解释；固定案例自评场景尚未真实运行 |
| A02 不同基础同一知识点 | `test_tutor_quality.py` 与评测包提供同题成对背景输入 | 真实生成后的教法、顺序和活动差异及合理性；不能用上下文不同证明输出个性化 |
| A03 学生坚持先做 Lab | `test_ui_assessment.py` 可进入实验再返回；`test_ui_lab_support.py` 提供显式帮助选择 | 正式单元的先修缺口解释与真实模型自主选路质量 |
| A04 受助后迁移 | `test_assessment.py`、`test_assessment_lab_help.py` 区分提示、重复曝光和独立作答；教学流程浏览器走到未曝光复测 | 正式课程迁移任务的等值性与评价质量 |
| A05 成果对而解释错 | `test_ml_lab.py` 保留技术检查与解释证据，实验完成不直接制造概念诊断 | 正式错误解释案例中真实模型的识别与后续补学；实验正确率不替代该证明 |
| A06 讲义实验补学回返 | `test_ui_assessment.py`、`test_ui_react_lab.py` 检查讲义返回、参数草稿和已保存实验步骤 | 正式课程综合路径与所有材料形式的回返体验 |
| A07 跨次恢复 | `test_ui_access.py` 跨浏览器恢复；`test_ui_lab_support.py` 首页续实验；PDF／视频浏览器恢复保存位置 | 共享部署中实际会话与数据恢复演练；本地未提交草稿不承诺跨设备自动同步 |
| A08 生成中切换课程 | `test_ui_course_switch.py` 验证对话迟到结果；`test_ui_flow_course_switch.py` 验证采用范围后的自动活动：A 生成中切到 B，B 生成并留草稿，观察 A 已保存时 B 仍挂载且不受覆盖；返回、刷新恢复正确活动，无重复生成。另有版本变化／暂停后的迟到提交测试 | 已验证手动对话与自动初诊活动；真实供应商断连行为、部署并发及其他在途操作仍需继续核验 |
| A09 双标签与重试 | `test_assessment_jobs.py`、`test_teaching_jobs.py` 与教学流程测试覆盖请求幂等、并发生成与提交冲突 | 真实部署负载下的恢复与持久化表现；不承诺供应商恰好计费一次 |
| A10 模型失败 | 持久任务测试和教学流程浏览器覆盖失败保留、停止自动重试、显式恢复 | 实际供应商超时、限额和格式错误验证；病例结构通过不证明内容正确 |
| A11 摄像头授权拒绝撤回 | `test_ui_camera.py`、`test_ui_camera_denied.py` 验证授权前不打开设备、拒绝／暂停／撤回、活动切换关闭 | 测试使用合成视频与拒绝模拟；实际设备兼容、授权方案与留存责任尚需落实 |
| A12 片段与活动回看 | `test_media_timeline.py` 校验活动、缺口与字段；摄像头浏览器覆盖片段回看 | 真实设备时间误差和活动对齐精度；现有近似时间轴不是微表情分析 |
| A13 身份隔离 | `test_access.py` 与身份浏览器验证服务端归属、恢复码轮换和管理边界；包含档案草稿名称泄露回归 | 部署模式、HTTPS、可信代理和全部外部访问路径的实际核验 |
| A14 更新与导出 | 档案版本测试、PDF 导出与实验历史浏览器验证保存版本和恢复；Word 有候选转换器 | Word 逐页渲染验收未完成；全套正式长材料及完整个人教材汇编未验收 |
| A15 三主题和窄屏 | `test_ui_student_app.py` 切主题保留草稿、刷新恢复与窄屏检查；各材料浏览器补充局部检查 | 全组件键盘焦点、对比度、复杂图表和真实材料规模的完整视觉与性能检查 |
| A16 恶意公共资料 | `test_tutor_quality.py` 检查系统／资料分离及输出契约；`test_source_injection_pipeline.py` 通过受保护真实上传、TXT 解析、原文检索、教学接口及生成函数验证资料仍处于数据区，越界目标被拒绝，课程及他人记录不变。七例评测包包含来源注入 | 仍需真实模型响应评审；本链路的课程关联为显式合成夹具，不证明 LLM 图谱抽取与自动核验安全。字段拒绝不能证明模型不会在普通回答里复述或遵从恶意内容 |

## 2 不依赖用户确认仍可推进的工程工作

1. A08 已补教学对话及自动初诊活动跨课程迟到响应浏览器用例；A16 已补上传解析至教学调用的工程集成用例，真实供应商行为、模型语义评审及自动知识抽取核验仍需继续验证，付费评测前明确预算。
2. 视频已支持作者指定片段元数据，内容索引仍待完善；个人教材已增加阶段报告引用范围内的在线汇编及合并 PDF，继续验证正式长材料、全范围呈现与 Word 排版。不用片段元数据冒充视频语义理解，也不用单篇导出冒充全部完成。
3. 完善隐私删除与备份恢复路径、部署前配置核验及并发资源控制；实际删除和部署必须在明确对象与环境下操作，不自行清理用户数据。
4. 已建立 200 篇合成材料的本机导航、翻页、主题切换基线，脚本 test_ui_performance_baseline.py 记录环境、样本与计时定义；继续核验真实材料规模、完整键盘及对比度、慢网络和多人并发。该基线不证明线上性能，也不宣称技术选型“性能最好”。

## 3 需要用户或环境提供的前置条件

1. 2026年10月10日用户已确认首个正式单元为“数据划分与过拟合泛化”。仓库已有相关自编内容、20 道客观题及官方来源链接；继续复用并核对来源、补齐正式评价与迁移任务，不把验收演示课程简单改名为正式课程。此项不再等待用户重复确认单元。
2. 用户已确认沿用 Qwen，本轮评测费用不限；当前配置核对为 qwen-plus。允许开展有界的合成案例真实调用，仍需记录、审阅结果，不把授权解读为真实学生资料或媒体外传授权。
3. 用户已确认先本机验收。多人真实试用前还需身份与部署核验、摄像头授权、保存期限、删除责任与展示用途。
4. Word 所需托管依赖与逐页渲染环境。现有工具未提供指定依赖加载入口，未通过视觉验收前保持候选导出默认关闭。

## 4 交付规则

1. 继续在 `feat/agent-learning-platform` 修改。代码、测试通过与方案吻合分别记录，不修改原目标范围。
2. 正式课程中完成目标协商、起点判断、学习实践、证据诊断、教学调整、保存导出和恢复，并完成授权／拒绝两种摄像头路径与受控真实试用后，才能声称平台首轮完成。
3. 最终交用户核验。未经用户明确同意，不提交或推送。本清单不是比赛材料中的状态标签模板。
