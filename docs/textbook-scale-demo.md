# 计组教材大图示范

从课程列表进入 **计算机组成与设计：全书大图示范**，点击“讲义与知识图谱”。直接入口为 `/course-reader?course_id=computer_organization_demo`；“课程练习”进入独立学习记录空间。所有课程使用同一套卡片、讲义阅读、图谱交互和学习工作台。

## 内容与来源

材料来自已经上传的《计算机组成与设计：硬件／软件接口（第二版）》：文档编号 `1430eae9d93742068badc82af0bddff9`，513 个 PDF 物理页，628,550 个 OCR 字符。原书印刷页码与 PDF 页码不同，界面来源按钮使用 PDF 物理页码。

- 原有历史候选图谱保留 500 个术语、2,000 条关系。1,998 条是共现，另有 2 条包含候选。它们独立于课程教学关系，未转换成先修边。
- 无损快照保留原图、结构信息、OCR 文本和页码；21,580 条节点或关系引文都通过逐字核对。核对证明引文存在，不等于术语合格、关系正确或完成了人工教学审核。
- 全部六章与附录 A 均有导读、自编算例、自检题及参考答案。全书导读 13 页，各章节/附录版本各 3 页。导读是入口主题的概括，不是全书逐小节精讲。
- 附录 A 从 PDF 第 444 页开始，单独列出；前言和书末材料仍保留在全书来源快照中。
- 每个候选术语可打开最多 8 个来源页；完整引文仍在原始快照内。跨章节概念可出现在多个章节投影中。
- 课程状态为 `source_demo`，不是正式发布。作答写入独立 learner store，等待复核，不调用机器学习示范课程的 `demo-choice-v1` 评分，也不自动生成掌握诊断。

课程资源位于 `data/courses/computer_organization_demo/`。首次访问把已打包讲义解压到 `outputs/course_graph/source_demo/computer_organization_demo/v1/handouts`；学习记录在同一课程的独立目录中。无需模型调用、重新上传或重新 OCR。原始 342 MB PDF 不复制入项目；离线来源按钮打开随快照保存的 OCR 原文。

课程通过通用 `package.json` 自动登记，没有按课程 ID 分流的页面或学习逻辑。预装讲义和后续生成的讲义共用同一任务列表、阅读器与生成管线；点击“生成”会基于已关联的课程资料调用配置的模型，新任务不会覆盖预装快照。生成入口的回归检查使用替代模型，未计入真实模型质量验证。课程的固定 v1 内容仍只读，来源与审核状态保持原义。

## 实测范围

2026-10-09，本机 headless Chromium 149.0.7827.55、1440×1000 窗口，隔离临时课程库，新浏览器上下文，一次功能验收中的测量：

| 操作 | 时间 |
|---|---:|
| 首次从课程列表打开全书图谱，包含首次资源展开 | 1,968 ms |
| 选中节点，高亮完成，5 次中位数 | 289 ms |
| 搜索“寄存器”并更新按钮结果 | 18 ms |
| 切到第一章 | 90 ms |
| 切到第五章 | 159 ms |
| 切到附录 A | 145 ms |
| 返回全书图谱 | 206 ms |

全图 JSON 解码后 1,943,751 字节。选中时间包含约 220 ms 的视觉过渡及浏览器自动化开销。运行时未发现 pageerror；来源弹窗、目录跳转、PDF 下载和手机宽度/深色布局通过检查。

这是本机的一轮交互验收，不是多设备统计、并发负载测试或真实学习者试验。本轮复用已完成的 OCR/原始图谱，不测 OCR 耗时、全书模型生成耗时或生成质量。历史图谱的 500/2,000 是原抽取显示上限，不能把这轮测试称为展示了全部候选；原任务报告另外丢弃了 2,577 个节点候选、14,580 条关系候选。

原始测量和截图位于 `outputs/verification/textbook-demo-performance.json`、`textbook-demo-full-graph.png`、`textbook-demo-guide.png`、`textbook-demo-mobile-dark.png`。测试只在临时目录写合成学习记录，不修改现有用户记录或原教材。

## 复测与构建

```powershell
python -X utf8 tests/test_textbook_demo.py
python -X utf8 tests/test_ui_textbook_demo.py
```

离线重建资源时，必须保留原教材的 `graph.json`、`job.json`、`outline.json` 和 `pages/`：

```powershell
python -X utf8 scripts/build_textbook_demo.py --source outputs/documents/1430eae9d93742068badc82af0bddff9
```

构建器核对证据后使用 LearnMargin 核心渲染导读，保存压缩快照、课程定义、讲义资源包和 SHA-256 清单。它是历史数据导入器，不是知识图谱生成器；不会把词频/共现包装成语义关系修复。已安装的 v1 资源不可覆盖，调整课程内容并交付新版本时应增加版本目录，保留旧学习记录。
