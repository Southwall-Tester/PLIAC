# 学习活动与内容负荷休息规划

## 当前交互

课程阅读区可收起讲义后作答，记录作答前把握、回看材料和提示使用。到期复测默认收起讲义。重新收起材料不会抹掉已经发生的回看，旧记录保持原样。对照材料答对与独立核验分开；正式课程仍须教师复核。个人解题卡保留学生原话和历次证据，在知识手册中先回想、再展开核对。综合练习从课程导航单独进入，反馈记录与掌握诊断分开。

ML Lab 保持原有五步主线、实验引擎、提示、验收和迁移任务。本轮不向 Lab 加入回想、预测、反思问卷或混合辨析，只增加侧栏休息机会。

## 休息位置如何计算

参考本地 LearnMargin 的 `src/learnmargin/study_rhythm.py`、`models.py::StudyLoad` 和 `references/learning-design.md`，采用“内容负荷 → 不可分割的完整任务块 → 跨块累计 → 选择邻近完整边界”的规划方式。来源项目：https://github.com/Southwall-Tester/LearnMargin 。[MIT 授权](third-party/LearnMargin-LICENSE.txt)。实现位于 `src/pliac/rhythm.py`。

1. 为概念讲解、完整例题、练习组或实操任务提供负荷。支持作者/模型填写 `minutes` 与 `rationale`，也支持按语义任务数量估算；没有按字数、页数、章节号或停留时间推算实际学习时间。
2. 当前语义估算的单位权重：概念理解 1.2 分钟、决策 1.5、核对 1、计算 1.5、比较 2、实验运行与检查 2、文字解释 2、客观练习 2。它们是可修改的产品初始估计，不是认知科学测定常数；运行权重包含人的配置和阅读结果，不是 CPU 耗时。
3. 默认选择最接近 25 分钟规划负荷的完整边界，同时比较目标前后两侧；中间停顿至少积累 15 分钟，未达到目标的最后一段至少 20 分钟才增加提示。同距离选择较早边界。短章节合并、轻量练习成组，完整推导或实操步骤不被拆开，短尾段不凑提示。
4. Lab 根据实际任务合同生成顺序块，失败提交后的检查修正会小幅增加相应任务负荷（最多三次），不据此生成能力判断。课程按已经访问的小节累计，并沿当前课程路线预看后续完整内容边界。实际到达当前内容边界后才显示相应侧栏提示。
5. 用户可以休息或继续；选择与当时的规划依据原子保存，刷新不会重复同一提示。该位置之后重新累计。没有倒计时、强制等待、自动锁定或因为跳过休息而扣分。

`data/study_loads.json` 保存当前示范课与 Lab 的语义工作量、内容指纹和估计依据。它没有预先指定休息在第几节或第几步。修改负荷或插入任务会改变位置；内容指纹变化而估计未更新时，该块作为未知负荷屏障处理，避免沿用失效估计。正式课程可通过节点 `study_load` 提供下列块列表；任务合同也可以直接提供 `study_load`。

```json
[
  {
    "boundary": "concept",
    "load": {"minutes": 8, "rationale": "理解三个相互依赖的概念与一个完整推导。"},
    "resume": "接着阅读本节例子。"
  },
  {
    "boundary": "practice",
    "load": {"units": {"questions": 2, "checks": 1}, "rationale": "两道轻量题及统一核对，共用一个边界。"},
    "resume": "从本节反馈继续。"
  }
]
```

阅读边界对应 `lesson_content` 的段落 ID，`practice` 对应整组作答与反馈。未知或非法估计不会用默认时长补齐。规划结果的 `blocks`、`plan`、`rationale`、`policy_version` 和用户选择保留在 API/记录中，操作界面只显示休息建议和接续动作。

## 验证与校准

`tests/test_rhythm.py` 覆盖短段累计、两侧选点、不可分割长任务、短尾段、未知/失效估计、不同负荷使提示移动、用户选择后的恢复。`tests/test_study.py` 覆盖材料帮助记录、独立证据、解题卡、综合练习及复习阶段。浏览器检查覆盖真实侧栏、继续主线、刷新恢复、深色和手机布局。

当前估计依据任务内容编制，尚无真实学习者用时校准。后续可在自愿试跑中比较每块实际完成负荷与估计，按任务类型修正权重；测试验证位置计算和交互，不证明个人所需学习时间准确。侧栏从不声称“你已学习 25 分钟”。

示范课仍沿用固定 v1 的两道题。到期复测通过会推进复习阶段，但已看过提示或解析的旧题不会恢复成未见题；题目用尽后需要补题或教师复核。
