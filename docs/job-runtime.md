# 教学生成任务恢复

## 跨课程的进程内总容量

1. `PLIAC_TEACHING_MAX_ACTIVE_PER_PROCESS` 默认 8，允许整数 1—64；与每课程限制同时生效。覆盖调用 durable_generation 的教学、评价、规划和知识核验任务，不覆盖旧讲义生成等独立入口。不是跨进程或供应商全局配额，部署多个进程时不能把 8 当作整个部署的总上限。
2. 已有缓存和相同正在执行请求先查询；缓存仍可读取，原在途请求返回原状态。新生成无名额时返回 429，不创建任务行、不增加尝试次数、不调用模型，不无限排队。查询可能初始化任务库结构，不声称完全无磁盘写入。
3. 名额覆盖任务领取、生成及结果落盘，结束、失败和服务端取消均释放。浏览器断连不会取消持久任务，也不会提前释放仍在生成的名额。服务端关闭后的供应商处理和收费仍须由供应商配额管理；此限制不是费用预算，也不证明教学内容质量。

## 同课程并发容量

1. `PLIAC_TEACHING_MAX_ACTIVE_PER_COURSE` 默认 4，允许整数 1—32。该值限制同一课程任务库中租约有效的活动任务，覆盖使用持久任务机制的讲解、评价、规划及自动知识核验。配置无效时拒绝新生成，不默默取消限制。
2. 容量校验与任务占用在同一 SQLite 写事务中完成，共享此任务库的进程不能分别越过同课程上限。繁忙返回 429，不创建新任务、不增加原任务尝试次数、不调用模型；界面保留原请求供稍后显式重试，不提供无限自动排队。
3. 已缓存的生成结果和已经执行中的同一请求先按原规则处理，不因容量满而丢失缓存或重复生成。任务正常完成、失败或中断后释放名额；失去心跳的租约到期后可恢复。
4. 这是任务租约容量，不是供应商连接数或费用的严格上限。供应商仍处理已断开的请求、租约过期或进程故障时可能发生额外费用；跨课程合计、其他旧生成入口、跨主机不共享任务库的实例不在本限制内。共享部署仍需供应商配额、总预算与负载验证。

## 原任务恢复规则

1. 教学任务默认最多三次显式尝试。达到上限后不无限重试，也不自动换请求编号绕过限制。浏览器断连不代表服务端任务已停止。
2. 在启用身份保护的环境中，管理员可从账户页进入“教学任务恢复”，提供课程、学习者和任务编号，先读取当前状态，再填写检查结果与原因。学生对话的未完成请求中可展开“故障协助信息”；不应索取恢复码或模型密钥。
3. 管理恢复只给原任务增加三次尝试额度，累计上限十二次。不会自动调用模型，不重置已用次数，不修改学习画像。学生仍需显式恢复原请求，服务端仍校验原上下文；上下文变化时不能强行保存旧结果。
4. 正在执行或已有成功生成结果的任务不得恢复额度。接口核验管理身份和预期计数，同一恢复请求不能重复增加额度；恢复后旧执行者不能覆盖任务结果。恢复记录包含管理身份、目标任务、原因、计数和时间。
5. 次数限制不是费用预算或全局限流。供应商已执行但进程未保存结果时，重试仍可能产生额外费用；不能承诺恰好一次计费。此次功能不提供完整任务取消中心，也不证明模型教学内容准确。
6. 验证使用临时数据、合成任务及独立浏览器，不调用付费模型、不采集真实学生数据。后续共享部署前仍需验证实际模型配置、并发负载与备份恢复。
7. 自动知识核验复用同一任务机制。管理员可通过 `/api/tutor/activation-status?course_id=课程编号` 查询当前草稿与来源对应的 `job_id` 和 `job_owner`，后者固定为 `knowledge-activation`，不是学生身份。需要管理恢复时用这两个字段定位原任务；状态 generated 不代表最终发布成功，仍须核对课程可用版本。开发默认模式不提供共享访问隔离，正式环境必须启用身份保护。
8. 心跳续期失败时停止本地生成，不继续等待其正常完成；原执行者失去任务归属后不能写入成功、失败或中断覆盖新执行者。生成超时返回 504，取消本地生成并等待清理，释放本地容量。这里依赖生成协程响应取消，不保证远端供应商立即终止计算或计费；无法访问任务库时，持久状态仍可能需要租约到期后恢复。
