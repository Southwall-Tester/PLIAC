# 机器学习 Lab

## 新工作台接入说明（2026年10月10日）

1. API 支持 course_id，未提供时兼容原演示课程。正式课程须在知识版本中配置 ml_lab.node_mapping，键为实验合同的全部技能 ID，值为该课程真实知识点 ID；没有映射的课程不能启动此实验。
2. 请求使用接口返回的 course_version，不固定填 1。实验轮次保存课程版本和映射，更新后禁止把旧轮次直接写入新版本，历史保留待迁移。
3. 新工作台的教学材料可进入旧 Lab 页面，再返回原材料地址。当前为过渡接入，不代表 React 实验界面已经重建。
4. 实操验收与解释性评价分开，导出中的 pending_evidence_assessment 表示解释证据尚待评价，不是等待人工审批。

入口：课程首页 → 机器学习分类入门 → 进入机器学习 Lab，或 `/ml-lab`。

## 学生怎样完成实验

输入匿名编号，选择情境并填写本轮目标。当前提供轨道站设备预警、海洋站样本分流、训练馆器材巡检三套编写好的情境。每套情境使用同一分类任务、数据生成方法和验收条件。

| 步骤 | 实际操作 | 保存的成果 |
| --- | --- | --- |
| 检查数据 | 阅读数据和字段产生时间，选择目标和特征 | 目标、特征、时间判断及原始作答 |
| 划分数据 | 设置训练比例和验证方式，运行一次训练 | 训练/验证/测试样本数、重叠数、划分哈希 |
| 比较模型 | 在相同划分上比较深度 1 和自由生长的树 | 真实准确率、混淆矩阵、树节点数和判断 |
| 选择方案 | 增加中等深度，依据验证表现选择模型 | 被引用的实验、比较依据、文字解释、封存配置 |
| 封存与测试 | 提交测试职责判断和解释，完成最终测试 | 已封存模型的测试结果、作答证据和本轮报告 |

数据为 `make_moons(n_samples=600, noise=0.28)` 生成的教学模拟数据。`x1`、`x2` 对应预测时可得的两路读数，`target` 为类别，`receipt` 模拟事后产生的回执。加入回执或复用训练样本可以运行并观察结果；规范实验的验收会核查特征和样本是否分离。

每轮保留固定数据种子和固定测试集。训练比例可以为 50%、60%、70%，测试集固定 20%，其余为验证集。普通实验调用不计算测试分数。选择方案通过后禁止新增训练；最终测试使用被选定实验的配置和训练集重新拟合同一个确定性模型。测试不用于挑选模型。

答错先给方向提示，继续尝试时逐步展开，最多三级。已经使用的提示保存在服务端，刷新后恢复。通过实操验收后，可以换新种子开始迁移复测；旧轮次保留。记录上限为每名学习者十轮、每轮六十次训练。

实验包 JSON 包含全部轮次、参数、指标、提示、作答、证据引用，以及当前轮每次实验的独立 Python 脚本；页面代码区也可直接下载 `.py`。复现代码注明 scikit-learn 版本，在本地 Python 环境中运行即可比较结果。

## 借鉴 LinuxLab 的设计

参考 [LinuxLab](https://github.com/Southwall-Tester/LinuxLab/tree/8707841217450f8c89c7848fe65b4c92b3654f45) 的 README、`scene_blueprint.py` 和任务合同组织方式，借鉴下列结构，由 PLIAC 重新实现：

- 学习目标、步骤、知识点和检查规则稳定，故事中的角色、动机和字段展示名称独立。
- 检查实际操作成果：LinuxLab 读取文件与运行现场，ML Lab 读取服务器实际训练与划分结果。
- 按需分级提示，保留尝试过程，恢复同一轮实例。
- 完成后保留可导出的成果，并以新数据再验证实践方法。

当前情境来自本地编写模板，首次开始时保存文案快照。模型生成情境、语义复核以及任意 Python 代码的隔离执行是后续接口；本轮执行的是固定实验引擎接受的参数。

## 平台内的职责和数据

| 文件 | 职责 |
| --- | --- |
| `src/pliac/ml_contract.py` | 情境模板、五个任务的目标、节点映射、验收说明与提示 |
| `src/pliac/ml_engine.py` | 真实数据生成、划分、训练、指标计算与独立 Python 复现代码 |
| `src/pliac/ml_lab.py` | 轮次、步骤、检查、提示与实验的事务编排 |
| `src/pliac/ml_api.py` | `/api/ml-lab` 查询、操作、导出 |
| `static/ml-lab.*` | 学生实验工作台 |

Lab 使用现有 `ml_acceptance_demo` 学习档案。`workspace.ml_lab` 保存轮次和实验检查；原始学习解释以 `practice` 写入知识节点证据，含任务与骨架版本；实验指标以 `technical / system_observation` 写入。两者引用连接，保持独立。已有教师复核和知识手册可以直接读取这些证据。

实操完成依据五步合同。文字解释保存给教师复核，长度检查用于确认已经填写，内容正确性由复核处理；实操检查不会直接把概念图谱全部标绿。服务器校验请求版本和会话编号，相同请求编号可安全重试，跨标签页更新冲突会要求刷新。
