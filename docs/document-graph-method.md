# 书籍到课程知识图谱

书籍先生成带原文出处的资料图谱，教师再把选定概念和关系加入课程草稿。课程正式发布继续采用 v7 §3.2 的人工核验与版本机制。节点大小表达层级；资料出现次数和连接数量不决定节点大小，也不用于判断学生掌握程度。

[构建架构与实现对照](document-graph-architecture.md)将 Docling、Microsoft GraphRAG、EDC 的依据逐阶段对应到本项目函数，并标出已实现部分、方法差异和固定源码版本。

## 方法依据

| 材料 | 实际方法或论点 | 本项目采用的设计 |
| --- | --- | --- |
| [EDC，EMNLP 2024，§3.1–3.2](https://aclanthology.org/2024.emnlp-main.548/) | 将三元组抽取、关系定义、规范化分开；语义相似候选仍要结合上下文验证后再对齐。 | 先形成候选，再做名称归一与关系类型校验；保留合并前的出处。课程关系仍遵循 v7 的四种类型。 |
| [REBEL，Findings of EMNLP 2021，§3–3.2](https://aclanthology.org/2021.findings-emnlp.204/) | 以训练后的 BART 生成可还原的三元组；讨论把实体共同出现当成关系成立所产生的标注噪声。 | 三元组保存两个端点、明确关系和原文证据；共同出现单独标作“共现”，不自动变成先修关系。 |
| [GraphRAG，§3.1.1–3.1.2](https://arxiv.org/html/2404.16130v2) | 长文先切成文本块，再抽取实体、关系及描述；块大小影响调用成本与召回。后续社区摘要服务全局问答。 | 逐页解析、分块抽取、跨块汇总，保留页码和片段定位。当前书籍建图任务采用前半段处理思路。 |
| [Docling 技术报告 v5，§3](https://arxiv.org/html/2408.09869v5) | 将 PDF 后端、页面 OCR/版式/表格模型和文档组装分开处理。 | 参考解析分层；当前实际使用 PyMuPDF 与 RapidOCR，未接入 Docling 及其表格、版式模型。 |

这里是方法借鉴：项目的本地术语与规则抽取、可选模型调用，不等于复现 EDC 的训练检索器、REBEL 的训练权重或 GraphRAG 的社区问答实验。论文报告的实验结果不能作为本项目中文教材抽取精度。

用户提供的《知识图谱与深度学习》补充了三个直接约束：PDF 第 18 页（书内第 4 页）用实体—关系—实体描述知识；PDF 第 26、84 页（书内第 12、72 页）说明实体共现的远程监督假设会引入错误关系；PDF 第 141、143 页（书内第 129、131 页）讨论实体对齐，以及错误硬对齐的传播。因此，自动归一应保留证据，相似名称需要结合定义和上下文审核。

## 数据链路

1. **解析**：PDF 保留物理页码；可复制文字优先使用文本层，扫描页执行中文 OCR。正文与页码一起落盘，来源文件保留供回看。
2. **切块**：按页内正文分块，并记录字符起止位置。抽取引用定位到保存的解析正文；OCR 引用对应识别文本，核验时同时查看页面图像。
3. **抽取**：本地引擎提取术语、显式关系与共现；模型引擎按当前配置处理文本块，输出接受同样的结构和原文校验。
4. **归一**：规范文字形式，汇总相同候选的多处证据；语义相近不直接表示同一个知识点。跨教材的同名异义尤其需要复核。
5. **建图**：资料、章节和概念承担层级导航；概念之间表达关系。层级边、语义边、共现边应在数据和显示上可区分。概念可以关联多个出处。
6. **入课**：将选定候选及证据加入课程草稿，经过现有审核和发布流程。只有审核后的先修边参与学习顺序约束。

资料标题、章节标题是结构信息，不能用“书包含某章节”替代概念关系抽取。书籍中的“依赖”“基于”也未必是在规定教学先修顺序，需结合课程目标审核。

## 配色规则

颜色编码类别与层级：[ColorBrewer](https://colorbrewer2.org/learnmore/schemes.html)用色相区分类别、明度表达顺序；[Carbon](https://v10.carbondesignsystem.com/data-visualization/dashboards/#use-consistent-color-assignments)要求同一数据组保持一致配色；[D3](https://d3js.org/d3-scale/ordinal#ordinal_domain)建议显式定义类别映射，避免颜色随调用顺序变化。基于这些通用原则，本项目约定：

- 课程教师视图按学习单元分色；资料按第一层有效章节家族分色，后代沿用该色相，结构节点到概念节点以有限明度层次区分。采用绿、粉、紫等中等饱和色，课程/书籍根节点用柔和紫色；顶栏统一采用中性色，避免暗示按钮与节点族群的关联。
- 颜色绑定稳定的单元或章节标识，在搜索、折叠、排序后保持。跨章节概念保留全部归属边，以固定主归属决定填色；图例展示家族名称。
- 正式学习视图默认按掌握状态着色，并提供“单元 / 掌握”切换及对应图例。类别色与掌握状态色分别使用，节点文字、层级和详情同时表达信息。
- 连线沿用起点节点色系，常态透明度低于节点；悬停时关联边渐显。实线、虚线与箭头继续表达关系类型，颜色不新增关系语义。
- 顶栏按页面状态显示可用操作：资料库、生成中与待发布页隐藏图谱工具；图谱筛选无结果时保留筛选入口；布局与整理在画布有至少两个节点时出现。编写页提供导入和管理，正式课程提供学习画像。

“同族同色相、层级分明度”是本项目对资料结构的设计选择，未将其表述为知识图谱的唯一标准；明度在这里表示结构层级，不代表重要性、难度或掌握程度。

节点尺寸由层级固定：根 42、章 32、更深层级 26/22/19/17/15、概念 12。初始布局完成后静止，交互或主动整理时再更新位置；大小与持续运动不用于表现节点热度。

## 验证办法

| 维度 | 核验内容 |
| --- | --- |
| 页面解析 | 扫描页是否实际执行 OCR；文字层中的水印、乱码、页眉是否被识别为噪声；公式、表格是否保留可回看的原页。 |
| 概念质量 | 人工检查名称是否为完整学科概念；统计重复、碎片词、泛词和 OCR 错词。以人工标注的教材片段计算准确率与召回率。 |
| 关系质量 | 分别检查关系类型、方向、否定、条件与作用域；将共现与明确语义关系分别计数。不能把边数当成质量。 |
| 对齐质量 | 检查同义词漏合并、同名异义误合并；保留跨页原始证据，能够回查归一来源。 |
| 引用正确性 | 每条引用的起止位置切片必须逐字等于引用文字；人工打开对应 PDF 页核验语义支持，而非只核验字符串存在。 |
| 层级与浏览 | 展开章节、聚焦概念邻域、返回全图后结构仍一致；资料结构边不能改变课程的先修判定。 |
| 流程完整性 | 上传、处理中、完成/失败、重试、预览、加入草稿、版本冲突与发布隔离都需实际验证。 |

测试分为可重复的程序契约检查和真实教材人工抽查。前者证明数据链路及约束成立，后者发现抽取内容质量问题；二者分别记录。真实书籍、解析全文和页面截图保存在本机 `outputs/verification/`，不随代码仓库分发。

### 2026-10-08 本机抽查

使用 `scripts/verify_document_books.py` 在临时资料库执行完整解析、抽取、合并流程，实际结果如下。页码均为 PDF 物理页，时间为本机本次运行值。

| 资料与范围 | 本地抽取结果 | 引用核验 | 内容抽查 |
| --- | --- | --- | --- |
| 《知识图谱与深度学习》18–19 页 | 40 个术语，102 条共现关系；2.21 秒 | 236 处引用逐字切片一致 | 知识图谱、三元组、义原、HowNet 等可识别；HowNet 与义原归于 1.1，深度学习保留 1.1 与 1.2 两处章节出处。 |
| 《强化学习的数学原理》30 页（书内第 7 页） | 1 页实际 OCR；12 个术语，25 条共现关系；12.06 秒 | 107 处引用逐字切片一致 | 奖励、智能体、状态、动作、策略可识别；原文件目录为扫描编号，回退到第 30 页。 |

抽查推动修正了关键词拆碎、任意“包含”触发错误关系、跨行句子截断、同一页章节边界错归属、扫描编号误作章节等问题。残留泛词和公式变量仍需筛选；这两段的本地抽取结果为共现关系，没有检出明确语义关系。尚未配置模型进行这两份材料的语义抽取对照，也尚未制作足够的人工标注集，因此本记录不报告准确率或召回率。

复现命令：

```powershell
python -X utf8 scripts/verify_document_books.py "教材.pdf" --start 18 --end 19 --output outputs/verification/book-check.json
```

整本流程另以用户提供的《知识图谱与深度学习》完成实测：259 页、267 个文本块，其中 2 页执行 OCR。展示 500 个本地术语和 2000 条共现边，其他分块候选保存在任务目录。对展示图谱的 10936 处引文逐一检查页文本切片，均一致。此样例已保存在本机资料库，未加入或发布课程；本次结果为术语与共现图，非语义模型的效果验证。
