## 与原 ChatEval 的关系

上一版把图谱路由和入口接入 ChatEval，这与 v7 §5.1 不符。本次撤回的内容是本会话新增的路由、菜单链接、README 说明及图谱附加文件。恢复前先归档并核验 SHA-256；原研究代码、浮沉材料、数据和配置保持原位。

本地迁出归档为 `outputs/migration/previous_chateval_addon.zip`，附 `archive_manifest.json` 和 `old_integration.patch`。新的核心代码来自本会话新写的图谱模块并作了重构；没有复制原 ChatEval 的对话、录制、评分业务实现。原 B/D/I 实验公式未移植为新项目的通用能力量表。

独立仓库的 `origin` 已关联用户指定的 [Southwall-Tester/PLIAC](https://github.com/Southwall-Tester/PLIAC)。GitHub 代码仓库与实际服务部署是两件事，当前应用仍由本地启动器运行。

## 开源参考的取舍

- **wisdom-edu**：参考课程结构、学习状态与资源联动；未引入其业务代码。
- **Neo4j LLM Graph Builder**：参考先定义 schema 再抽取候选；当前规模采用 FastAPI、NetworkX 与 JSON，不需要独立图数据库服务。
- **LangExtract**：参考逐字证据定位，自行实现字符片段校验；并未安装该包，也不声称具有其全部能力。
- **AntV G6 5.1.1**：实际使用本地浏览器渲染包，保留 [MIT 许可证及来源校验](../static/vendor/NOTICE.md)。v7 §5.4 的 ECharts/Cytoscape 是待确认建议，保留已验证的 G6 不改变要求中的四态、节点点击与证据展示。

## 当前资产与整个平台验收的区别

40 节点、68 关系、4 项课程资源候选、12 道诊断题及 3 个实训骨架全部保持草稿。联网核查官方来源不能代替教师审核；测试中的合成审核只在临时目录内运行。正式输出目录中不预先写入学生掌握数据、人工审核结论或发布快照。

三份骨架记录固定步骤、目标节点、错误类型、提示分级与判定规格，缺少教师指定数据、比例/容差等参数时列入 `parameters_required`。它们是资产草稿，不是已经能执行的实训。兴趣只改变允许替换的情境外观；数据分布、步骤、判定与难度的不可变约束已写入骨架。

v7 §5.5 的全平台验收还包括初诊、动态教学小节、情境生成及一致性校验、Docker 隔离运行与判定脚本、实训过程采集、知识手册、章节推进、摄像头授权/关闭/回看及真实试跑。本次未将占位字段、静态资产、人工采录或浏览器合成测试冒称这些功能已完成。

本地教师工作台尚无权限认证。学习端隐藏教师管理入口和参考判据用于交互分工，不是安全隔离或考试防作弊保证；联网部署前需要完成账户与角色权限。

本轮查看用户指定书籍目录，并选读知识图谱、GNN、推荐系统、强化学习方向的 7 本书。两份 Linux 教材未用于改写本轮监督分类课程。相关书籍没有复制进仓库，选读范围与 PDF/印刷页对应记录在 [design_references.json](../data/design_references.json)。以下是结合 v7 做的工程适配，不是书中已验证的教育算法。

| 书籍依据 | 落实到软件的变化 | 与 v7 的关系 |
| --- | --- | --- |
| 《知识图谱与深度学习》PDF 18、26、84、141、143 页；GNN 书 PDF 3、6、11 页 | 增加只读概念/别名冲突、关系类型与方向、来源定位、孤立节点和间接路径核查；8 项课程出处有具体小节定位 | 辅助人工审核，不自动合并、删边、传播掌握或把共现当关系 |
| 《推荐系统实践》PDF 95、106、111、129–130 页；《深度学习推荐系统》PDF 177–178 页 | 内容与领域规则冷启动；按真实先修状态找到当前可行动节点，再过滤已审核、前置已满足的材料 | 先处理当前缺口，兴趣和点击不当作能力证据 |
| 《深度学习推荐系统2.0》PDF 139–140、160、244–245 页 | 确定性重排、覆盖与形态多样性、同 URL 同片段去重；每条资源记录选择或排除原因 | 页面解释具体选择；最多 4 项、零候选不补造内容；API 候选返回不称为已曝光 |
| 《强化学习的数学原理》PDF 25、28、30、32 页；《深度强化学习》PDF 50–51、54、56 页 | 记录完整状态快照、策略版本、决策前记录版本与已观察证据集合；后续诊断显式关联动作 | 补充“调整—后续核验”的可回查链条，无反馈保持等待，不把时序关联声称因果学习收益 |

后续核验必须为同一学习者、课程版本和动作目标，引用动作后新记录的任务作答。相同时间戳使用动作发生前的证据集合区分记录先后；旧证据不能混入本次后续评价。展示中同时保留本次判断与当前综合状态，因此历史冲突、复习到期或版本变化不会被单条“掌握”记录掩盖。旧动作缺乏完整快照时可以保留历史，但不能追补成已验证效果。

推荐规则版本为 `content-frontier-v1`。当前没有训练 GNN、协同过滤或强化学习模型，没有从点击生成奖励，也没有声称学习状态符合 MDP 假设。书籍引入的是治理、冷启动、可解释排序和序列记录的方法；学习效果仍需真实试跑与后续评估。

本轮本地验证：68 项后端/规则测试通过，原有 14 组浏览器检查与新增 9 组书籍参考相关交互检查通过。新检查覆盖核查页只读、资源选择、UI 绑定后续任务诊断、记录刷新保留及 390px 显示。当前课程仍为 40 节点、68 关系、4 项候选资源；实际运行目录没有合成审核或学习数据。GitHub 工作流另配置 Windows/Linux 规则测试和 Chromium 检查，其远端结果以 Actions 运行记录为准。
